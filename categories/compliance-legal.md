# Compliance & Legal

Use this category for regulatory, contract, or policy-conformance decisions that must be auditable.

## Submission format

```md
- [Name](URL) - Industry: one-sentence description of the Jev use case.
```

## Entries

- [LegalForecast-MTD](https://github.com/johnhughes3/LegalForecastBench) - Legal forecasting: benchmark that asks Jev to predict federal motion-to-dismiss rulings from the judge's written record and scores the calibrated probabilities with claim-defendant micro-Brier metrics.
- [Jev Policy Engine](https://github.com/BhavinM/jev-policy-engine) - Policy conformance: universal Policy-as-Code SDK that allows DevOps and security teams to enforce deterministic AI governance rules in YAML via Jev with audit mode and fail-closed controls.
- [Jev grievance triage](https://github.com/aen07/jev-grievance-triage) - Development finance: reads one grievance and returns an auditable triage decision built from 23 narrow calibrated questions, routing a reprisal claim for instance to a regional specialist with urgency set and identity fields redacted.
- [JevGate](https://github.com/sanketmuchhala/jevgate) - Institutional policy: a hybrid engine where Jev 1.14 supplies calibrated probabilities, a System-2 model supplies verdicts with quoted evidence, and Python owns the policy, the thresholds and the three-valued rule logic.
- [jev-pii](https://github.com/senthilsweb/jev-pii) - Compliance in SQL: Jev answers inside DuckDB as extra columns - a zero-to-one score or one option from a list - so personal data and the privacy regimes that apply become columns you can filter, join and count.
- [Jev ToS Checker](https://github.com/shohei81/jev-tos-checker) - Terms of service: a Chrome extension that reads the terms on the page you are viewing and points out the clauses that may work against you, shipped in English and Japanese.
- [Basura Vision](https://github.com/sipelepis/basura-vision) - Waste sorting: a zero-shot video pipeline that puts each item into one of four bins defined by a Philippine statute, which makes the taxonomy a legal requirement rather than a design choice.
